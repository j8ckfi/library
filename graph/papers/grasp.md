# GRASP: Generative Robotic Action Synthesis and Planning

## Abstract Summary
GRASP synthesizes complex multi-modal robotic manipulation trajectories using generative flow-matching policies conditioned on real-time visual tactile streams.

## Key Contributions
1. **Flow-Matched Trajectory Generation**: Smooth multimodal action chunk generation with bounded velocity jitter.
2. **Tactile-Visual Conditioning**: Closed-loop reactive manipulation under visual occlusions.
