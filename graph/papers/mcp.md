# Model Context Protocol Specification (stateless core)

## Abstract Summary
MCP is the agent↔tool protocol. Spec dated **2026-07-28** defines a **stateless core** (`https://blog.modelcontextprotocol.io`). This is a vertical spec, not a benchmark. Schema requires `arxiv_id`; it is empty because there is no arXiv. Evidence is the spec, not a leaderboard.

A2A (a2a-protocol.org v1.0) is agent↔agent and is only for two independent vendors negotiating. Human AGENTS.md (ETH 2602.11988) is how to put instructions on disk. SKILL.md progressive disclosure (agentskills.io) is complementary.

## Key Contributions
1. Stateless MCP core (2026-07-28) as the default agent↔tool transport.
2. Vertical: tools and resources, not agent↔agent (that is A2A).
3. Complements human-written AGENTS.md and SKILL.md; does not replace them.
