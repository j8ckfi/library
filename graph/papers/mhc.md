# mHC: Multi-Head Convolutional Sequence Backbones

## Abstract Summary
mHC demonstrates that multi-head 1D depthwise convolutions with dynamic kernel generation can match multi-head attention efficiency across long sequence modeling benchmarks with sub-quadratic compute.

## Key Contributions
1. **Multi-Head Convolutions**: Channel-independent dynamic convolution filters.
2. **Compute Efficiency**: Hardware-friendly 1D GEMM implementations on tensor cores.
