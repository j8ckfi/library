# MXFP4: Microscaling FP4 Formats for Next-Generation Accelerators

## Abstract Summary
MXFP4 explores the OCP Microscaling format specifications for FP4 training and inference across modern hardware accelerators (including AMD MI355X), providing robust numerical stability across extreme low-bit matrix projections.

## Key Contributions
1. **Microscaled Block Scaling**: Shared exponents across 32-element blocks preventing subnormal underflow.
2. **Cross-Architecture Support**: Standardized format implementation for emerging accelerator architectures.
