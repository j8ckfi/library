# Sherry: Efficient Low-Bitweight Compression with AngelSlim

## Abstract Summary
Sherry provides an end-to-end framework for structured low-bitweight model compression and hardware deployment within the Tencent AngelSlim ecosystem.

## Key Contributions
1. **Structured Quantization**: Preserves critical attention and MLP projection saliency in sub-4-bit weights.
2. **Production Deployment**: Optimized kernel integration for high-throughput inference engines.
