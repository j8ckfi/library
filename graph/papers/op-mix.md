# OP-Mix: Optimal Transport-Guided Data Mixing for Foundation Models

## Abstract Summary
OP-Mix optimizes pretraining dataset composition using Wasserstein distance minimization to target distributions, guaranteeing maximal representation coverage across token budgets.

## Key Contributions
1. **Optimal Transport Mixing**: Computes Wasserstein-optimal mixing ratios for heterogeneous corpora.
2. **Target Distribution Matching**: Matches pretraining token distribution to target benchmark representations.
