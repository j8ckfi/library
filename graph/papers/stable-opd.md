# Stable-OPD: Variance-Controlled On-Policy Distillation

## Abstract Summary
Stable-OPD develops gradient variance reduction techniques for on-policy student trajectory sampling, enabling stable scaling to large batch distributed distillation.

## Key Contributions
1. **Gradient Variance Reduction**: Control variates tailored for student sampling distributions.
2. **Scalable Distillation**: Enables massive token throughput across multi-node student-teacher pipelines.
