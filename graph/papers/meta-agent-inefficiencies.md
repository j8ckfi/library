# Inefficiencies of Meta Agents for Agent Design

## Abstract Summary
Expanding context with prior agent designs **hurts**. Break-even only on 2 datasets at n>15k. Together with MAC (2606.04455), this is why meta-agent search is not the default for building an agent.

## Key Contributions
1. Prior-design context expansion is net-negative on most datasets.
2. Break-even only 2 datasets at n>15k.

## Empirical Highlights
- Expanding context with prior designs hurts.
- Break-even only 2 datasets at n>15k.
