# MONA: Momentum Orthogonalization with Nesterov Acceleration

## Abstract Summary
MONA combines Nesterov accelerated gradient momentum with matrix orthogonalization, achieving faster early-stage loss reduction in large language model pretraining.

## Key Contributions
1. **Nesterov Orthogonalization**: Applies lookahead momentum states before Newton-Schulz matrix normalization.
2. **Convergence Speed**: Accelerates loss trajectory in high-learning-rate regimes.
