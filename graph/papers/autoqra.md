# AutoQRA: Automated Quantized Residual Adaptation

## Abstract Summary
AutoQRA automates layer-wise bit allocation and adapter rank tuning for quantized fine-tuning, maximizing performance per memory budget.

## Key Contributions
1. **Automated Layer Allocation**: Heterogeneous bit-width selection based on gradient sensitivity.
2. **Low Overhead**: Operates seamlessly within single-GPU memory constraints.
