# TD-MPC2: Scalable Robust World Models for Continuous Control

## Abstract Summary
TD-MPC2 scales model-based reinforcement learning across 104 continuous control tasks using a single architecture, combining Model Predictive Path Integral (MPPI) planning in latent space with terminal Value-function estimation.
