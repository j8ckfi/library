# Kimi-Linear: Scaling Linear-Complexity Attention for Ultra-Long Contexts

## Abstract Summary
Kimi-Linear outlines a hardware-aligned linear attention architecture enabling 1M+ token context window processing with constant GPU KV memory per sequence.

## Key Contributions
1. **Hardware-Aligned Linear Kernel**: Triton-optimized chunked matrix-state update kernels.
2. **Million-Token Scaling**: Flawless retrieval across 1M context Needle-In-A-Haystack benchmarks.
