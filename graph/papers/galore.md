# GaLore: Memory-Efficient LLM Training by Gradient Low-Rank Projection

## Abstract Summary
GaLore introduces low-rank projection of gradient matrices, reducing optimizer memory by up to 65.5% while training full-rank weights across 7B pretraining and fine-tuning workloads on a 24GB GPU.
