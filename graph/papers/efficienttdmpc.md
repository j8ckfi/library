# EfficientTDMPC: Accelerated Model-Predictive Control with Block Planning

## Abstract Summary
EfficientTDMPC advances model-based continuous reinforcement learning by introducing block-wise latent planning (built on BMPC principles), cutting online planning latency and outperforming TD-MPC2 across continuous control suites.

## Key Contributions
1. **Block Latent Planning**: Replaces single-step MPPI trajectory sampling with accelerated block-wise optimization.
2. **Continuous Control SOTA**: SOTA sample efficiency and runtime default for continuous control world models.
