# BitEmbed: Ultra-Low Bitwidth Embedding Table Compression

## Abstract Summary
BitEmbed targets embedding table memory consumption in large-vocabulary foundation models, compressing embedding weights to 1-bit and 2-bit representations with near-lossless semantic retrieval.

## Key Contributions
1. **Embedding Quantization**: Ternary and binary coordinate factorization for large token vocabulary matrices.
2. **Memory Footprint**: Reduces embedding table VRAM by up to 85%.
