# CausalMix: Causal Data Scheduling for LLM Pretraining Curricula

## Abstract Summary
CausalMix applies causal dependency graph estimation to order educational, scientific, and reasoning corpora throughout pretraining, reducing forgetting and improving downstream transfer.

## Key Contributions
1. **Causal Data Ordering**: Schedules prerequisite concepts prior to specialized reasoning corpora.
2. **Transfer Efficiency**: Enhanced retention across multi-domain pretraining stages.
