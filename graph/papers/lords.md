# LoRDS: Low-Rank Decomposition with Dynamic Sparsity

## Abstract Summary
LoRDS integrates dynamic magnitude sparsity into low-rank adapter updates, concentrating parameter updates on critical representation coordinates.

## Key Contributions
1. **Sparse Low-Rank Hybrid**: Combines low-rank projections with dynamic activation gating.
2. **Efficient Updates**: Reduces active parameter updates during backward passes.
