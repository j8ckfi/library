# AgentFold: Long-Horizon Web Agents with Proactive Context Management

## Abstract Summary
AgentFold folds web-agent history so a long browsing trajectory stays in a small active context. Active alternative on `task:long-horizon-tool-agent`. AgentFold-30B-A3B: BrowseComp **36.2%**. Not a dumped-prompt RLM and not a SWE harness.

## Key Contributions
1. Proactive folding of web-browsing history.
2. AgentFold-30B-A3B BrowseComp 36.2%.
