# W2S-OPD: Weak-to-Strong On-Policy Distillation

## Abstract Summary
W2S-OPD demonstrates that on-policy distillation enables weak teachers to elicit superhuman latent reasoning capabilities in stronger base student models through iterative self-correction.

## Key Contributions
1. **Weak-to-Strong Generalization**: Distillation protocol eliciting latent student capabilities beyond weak teacher limits.
2. **Iterative Bootstrapping**: Self-improving student-teacher co-evolution.
