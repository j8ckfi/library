# Nemotron-3-Ultra: Scaling Frontier Mixture-of-Experts

## Abstract Summary
Nemotron-3-Ultra details multi-hundred-billion parameter MoE pretraining architectures with optimized communication topologies and expert load balancing.

## Key Contributions
1. **Communication-Aware MoE**: Expert allocation aligned with multi-node NVLink/InfiniBand topologies.
2. **Frontier Scaling**: Demonstrates Pareto scaling curves across trillion-token pretraining runs.
