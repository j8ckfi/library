# H-SAE: Hierarchical Sparse Autoencoders for Multi-Scale Feature Extraction

## Abstract Summary
H-SAE extracts hierarchical multi-granularity dictionaries from deep activations, organizing features into tree-structured semantic taxonomies.

## Key Contributions
1. **Hierarchical Dictionary Learning**: Multi-tier sparse decomposition from coarse domain abstractions to fine-grained tokens.
2. **Taxonomic Organization**: Direct extraction of hypernym/hyponym relationships from transformer activations.
