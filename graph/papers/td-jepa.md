# TD-JEPA: Temporal-Distance Joint-Embedding Predictive Architecture for World Models

## Abstract Summary
TD-JEPA combines Joint-Embedding Predictive Architectures with temporal distance metric learning to construct non-collapsing, highly predictive latent world models for robotic planning.

## Key Contributions
1. **Temporal-Distance Metric**: Regularizes latent representations using true environmental temporal geodesic distances.
2. **Stable Non-Generative World Models**: Eliminates pixel reconstruction overhead during world model learning.
