# FEGA: Feature Effect Geometry Analysis in Sparse Autoencoders

## Abstract Summary
FEGA introduces Feature Effect Geometry Analysis, characterizing how sparse dictionary features interact non-linearly across transformer layers through Riemannian manifold estimation in activation space.

## Key Contributions
1. **Feature Effect Geometry**: Models non-linear interactions and cross-layer effects of SAE features.
2. **SAE Effect Geometry SOTA**: Default framework for analyzing geometric feature superposition and causal influence.
