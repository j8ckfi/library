# DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning

## Abstract Summary
DeepSeek-R1 establishes pure reinforcement learning for mathematical and code reasoning without supervised warmstart (DeepSeek-R1-Zero) and with cold-start distilled post-training.
