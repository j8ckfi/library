# SSM-Inspired Leaky Integrate-and-Fire Neurons for Neuromorphic Sequences

## Abstract Summary
SiLIF / C-SiLIF integrates continuous-time State Space Models with Leaky Integrate-and-Fire neurons, delivering state-of-the-art performance on audio and event-based temporal tasks trained end-to-end with surrogate gradient BPTT.
