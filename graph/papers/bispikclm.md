# BiSpikCLM: Bidirectional Spiking Causal Language Models

## Abstract Summary
BiSpikCLM adapts spiking neural dynamics for causal autoregressive language modeling, introducing bidirectional membrane potential state updates to preserve long-range semantic dependencies.

## Key Contributions
1. **Causal Spiking LM**: Autoregressive next-token prediction with leaky integrate-and-fire dynamics.
2. **Semantic Retention**: Membrane state persistence across multi-token sequence boundaries.
