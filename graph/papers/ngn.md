# NGN: Neuromorphic Gated Networks for Temporal Stream Processing

## Abstract Summary
NGN designs neuromorphic gating circuits that adaptively route continuous temporal streams across sparse spiking sub-networks based on event density.

## Key Contributions
1. **Event-Density Gating**: Modulates active spiking neurons according to incoming event burstiness.
2. **Extreme Sparsity**: Cuts simulated synaptic operations by over 50% on audio and event-vision streams.
