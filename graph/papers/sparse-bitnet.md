# Sparse-BitNet: 1.58-Bit Native Extreme Quantization with Dynamic Activation Sparsity

## Abstract Summary
Sparse-BitNet represents the 2026 BitNet line, combining native 1.58-bit ternary weight optimization with dynamic activation sparsity to push extreme quantization efficiency beyond original BitNet b1.58.

## Key Contributions
1. **2026 BitNet Line**: Native 1.58-bit ternary weights coupled with sparse dynamic activation gating.
2. **Energy Efficiency**: Achieves sub-1.5-bit effective compute cost with zero quality degradation relative to dense 2B4T baselines.
