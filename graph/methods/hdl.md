# HDL

## Method Overview
HDL (Hindsight-Divergence Localization) samples \(M<G\) complete roots. For each root token, compare \(\log p^0(y_i)\) under the original prefix with \(\log p^H(y_i)\) under a hindsight context (feedback + reflection). Branch at the largest \(|\log p^H-\log p^0|\). Fill the remaining group slots with fresh suffixes from those positions under the original task context. Group-relative advantages follow the host; continuation loss is suffix-only.

## When to Use
- Branchy long-CoT or agent RLVR where independent full rollouts waste tokens before the decision that hindsight revises.

## When NOT to Use
- Pass@1 default → `method:cispo`. Peer all-fail salvage → `method:graft`. AppWorld TGC → `method:canopy`.

## Relation to Existing SOTA
- Active plug-in on `task:math-code-rl-dense` beside `method:grpo` and `method:graft`, with agentic mention on `task:outcome-only-long-horizon-agent-rl`. Does **not** enter `current_sota`. Does **not** replace CISPO, GRAFT, GRPO-as-cite, or CANOPY.

## Gotchas & Failure Modes
- No dedicated repo as of 2026-10-01 (slime host).
- Hindsight is for branch *selection* only. Training continuations with the reflection in context is not HDL.
- Entropy branch points (TreeRL / BPO) are a different algorithm and lose in the paper's comparison.
- Prefix reuse reduces generation, not the group size. Do not shrink \(G\) and call the token cut HDL.
