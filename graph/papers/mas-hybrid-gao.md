# Single-agent or Multi-agent Systems? Why Not Both?

## Abstract Summary
MAS edge shrinks as models get stronger. Tokens **4–220×**. Hybrid cascade: **+1.1–12pp** with cost down. Complements the Anthropic June 2025 orchestrator-worker result (+90.2% vs single Opus 4 on *internal breadth research*, ~15× tokens). Neither replaces single-agent+tools as the default.

## Key Contributions
1. Documents shrinking MAS gap as base models improve.
2. Token blowup 4–220× for multi-agent graphs.
3. Hybrid cascade +1.1–12pp with lower cost when MAS is actually warranted.
