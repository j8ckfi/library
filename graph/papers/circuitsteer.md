# CircuitSteer: Steering Representations via Subspace Projections

## Abstract Summary
CircuitSteer establishes the state-of-the-art methodology for steering transformer representations using Sparse Autoencoder (SAE) subspace circuit projections, enabling targeted causal interventions without degrading downstream task performance.

## Key Contributions
1. **Subspace Circuit Steering**: Projects causal interventions along multi-dimensional subspace boundaries rather than 1D vectors.
2. **SAE Circuits SOTA**: Minimal off-target representation drift and high steering specificity.
