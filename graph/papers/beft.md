# BEFT: Binarized Efficient Fine-Tuning for Large Language Models

## Abstract Summary
BEFT introduces binarized low-rank adapters with integer scaling factors, reducing fine-tuning memory footprint to extreme lower bounds on resource-constrained accelerators.

## Key Contributions
1. **1-Bit Adapter Matrices**: Binarized low-rank updates optimized via straight-through estimators.
2. **Minimal Memory Footprint**: Fits multi-adapter fine-tuning into ultra-low memory budgets.
