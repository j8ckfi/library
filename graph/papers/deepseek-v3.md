# DeepSeek-V3 Technical Report

## Abstract Summary
DeepSeek-V3 presents a 671B parameter Mixture-of-Experts model activating 37B parameters per token, introducing Multi-Head Latent Attention (MLA), DeepSeekMoE, and Multi-Token Prediction (MTP).
