# MinPRO: Minimal Policy Relative Optimization for Efficient LLM Reasoning

## Abstract Summary
MinPRO introduces a minimal relative policy optimization objective that eliminates value baseline networks while maintaining smooth gradient dynamics on coding and math tasks.

## Key Contributions
1. **Minimal Relative Formulation**: Simplifies advantage computation without auxiliary reward models.
2. **Memory Efficiency**: Cuts actor-critic memory footprint by over 40%.
