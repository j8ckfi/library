# The Illusion of Multi-Agent Advantage

## Abstract Summary
Automatic multi-agent systems underperform CoT self-consistency, at up to **10×** cost. Default for `task:multi-agent-orchestration` is **do not**: single agent + tools. AIME is the MAS exception; SWE patches and τ-bench policy dialog are not.

## Key Contributions
1. Auto MAS vs CoT-SC on equal models.
2. Cost: up to 10× for no quality win.

## Empirical Highlights
- Auto MAS underperforms CoT-SC, up to 10× cost.
