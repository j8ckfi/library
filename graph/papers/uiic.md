# UIIC: Ultra-Fast Inter-frame Image and Video Codec

## Abstract Summary
UIIC formulates video coding as conditional inter-frame residual completion, eliminating optical flow estimation entirely to achieve sub-millisecond per-frame encoding speeds.

## Key Contributions
1. **Flow-Free Inter-frame Coding**: Residual conditional mapping without explicit motion field estimation.
2. **Sub-Millisecond Latency**: Ultra-low latency for interactive screen and cloud rendering pipelines.
