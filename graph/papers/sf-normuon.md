# SF-NorMuon: Scale-Free Normalized Muon Optimization

## Abstract Summary
SF-NorMuon develops scale-free parameter update rules for orthogonal momentum optimizers, enabling direct transfer of learning rates across model parameter scales without manual re-tuning.

## Key Contributions
1. **Scale-Free Invariance**: Eliminates dimension-dependent learning rate retuning across 1B to 70B parameter models.
2. **Normalized Update Norms**: Matches spectral norm trajectories across depth and width.
