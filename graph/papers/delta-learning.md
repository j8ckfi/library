# Delta Learning: Parameter-Efficient Target Alignment for Instruction Models

## Abstract Summary
Delta Learning formulates instruction alignment as targeted directional updates in activation space, enabling precise behavior modification without broad parameter drift.

## Key Contributions
1. **Targeted Directional Shifts**: Guides instruction tuning along explicit safety and capability axes.
2. **Representation Preservation**: Prevents catastrophic forgetting of core pre-trained knowledge.
