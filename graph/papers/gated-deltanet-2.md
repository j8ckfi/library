# Gated DeltaNet 2: Linear Recurrent Sequence Modeling with Dynamic Memory

## Abstract Summary
Gated DeltaNet 2 expands upon linear recurrent neural architectures with an enhanced dynamic delta memory rule, closing the expressivity gap with standard softmax attention on associative recall tasks.

## Key Contributions
1. **Enhanced Delta Rule**: Fast chunkwise associative memory update formulations.
2. **Linear Complexity**: O(N) training speed and O(1) state caching during autoregressive generation.
