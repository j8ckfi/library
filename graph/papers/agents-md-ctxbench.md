# Evaluating AGENTS.md: Are Repository-Level Context Files Helpful for Coding Agents?

## Abstract Summary
ETH evaluation of repository-level instruction files. LLM-generated AGENTS.md **hurts**: −0.5pp Lite / −2pp CTXbench and **+20%** cost. Developer-written files beat LLM-generated by **+7pp average (p=0.038)**. Put instructions on disk by hand. Do not `/init` them with an LLM.

## Key Contributions
1. CTXbench / Lite measurement of AGENTS.md quality.
2. LLM-generated files cost more and score worse than no file or human files.
3. Human-written repo instructions are the complementary protocol to MCP tools.

## Empirical Highlights
- LLM-generated AGENTS.md: −0.5pp Lite, −2pp CTXbench, +20% cost.
- Developer files vs LLM-generated: **+7pp avg, p=0.038**.
