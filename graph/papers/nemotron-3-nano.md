# Nemotron-3-Nano: High-Efficiency Small Language Model Architecture

## Abstract Summary
Nemotron-3-Nano explores parameter-efficient transformer architectural modifications for edge and on-device inference, maximizing tokens-per-second while preserving reasoning capabilities.

## Key Contributions
1. **Compact Attention Routing**: Reduced key-value projection overhead for on-device deployment.
2. **Throughput Scaling**: High tokens-per-second on mobile and edge accelerators.
